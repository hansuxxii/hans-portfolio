# Hans Bragas Portfolio

A responsive static portfolio for legal operations, contract coordination, administrative support, and small-business operations work.

## Preview locally

Open `index.html` directly or run a local static server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deploy with GitHub and Vercel

1. Create a new GitHub repository.
2. Push the contents of this folder to the repository.
3. In Vercel, choose **Add New → Project** and import the repository.
4. Leave Framework Preset as **Other** and deploy with the default settings.

Vercel will automatically publish future changes pushed to the connected GitHub repository.
